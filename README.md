# Portfolio Pessoal - Alan Ryan

Um portfólio elegante e responsivo desenvolvido com HTML, CSS e JavaScript, apresentando um design moderno e sofisticado com efeitos cinematográficos.

![Portfolio Preview](assets/images/alan-ryan-02.jpg)

## 🎯 Sobre o Projeto

Este é o meu portfólio pessoal onde apresento minha jornada como desenvolvedor front-end e técnico em enfermagem. O projeto foi desenvolvido com foco em:

- **Design responsivo e acessível**
- **Performance otimizada**
- **Interface moderna e elegante**
- **Experiência do usuário intuitiva**

## 🚀 Funcionalidades

- ✨ Design responsivo para todos os dispositivos
- 🎨 Efeitos visuais cinematográficos (film grain)
- 📱 Navegação intuitiva entre páginas
- 🔗 Links diretos para redes sociais e contato
- 🖼️ Galeria de imagens otimizada
- 📄 Página dedicada "Sobre mim"

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização e responsividade
  - CSS Grid e Flexbox
  - Animações CSS
  - Media queries
  - Variáveis CSS
- **Google Fonts** - Tipografia (Playfair Display, Crimson Text, Source Sans Pro)

## 💻 Como Executar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/0nF1REy/personal-portfolio.git
   ```

2. **Navegue até o diretório:**
   ```bash
   cd personal-portfolio
   ```

3. **Abra o arquivo `index.html` em seu navegador** ou use um servidor local:
   ```bash
   # Usando Python
   python -m http.server 8000
   
   # Usando Node.js (http-server)
   npx http-server
   ```

4. **Acesse no navegador:**
   ```
   http://localhost:8000
   ```
