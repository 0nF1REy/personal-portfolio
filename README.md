## 📖 Descrição

Um portfólio elegante e responsivo desenvolvido com HTML, CSS e JavaScript, apresentando um design moderno e sofisticado.

## 🚀 Funcionalidades

- ✨ Design responsivo para todos os dispositivos
- 🎨 Efeitos visuais cinematográficos (film grain)
- 📱 Navegação intuitiva entre páginas
- 🔗 Links diretos para redes sociais e contato
- 🖼️ Galeria de imagens otimizada
- 📄 Página dedicada "Sobre mim"

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização e responsividade
  - CSS Grid e Flexbox
  - Animações CSS
  - Media queries
  - Variáveis CSS
- **Google Fonts** - Tipografia (Playfair Display, Crimson Text, Source Sans Pro)

## 💻 Como Executar

1. **Clone o repositório:**

   ```bash
   git clone https://github.com/0nF1REy/personal-portfolio.git
   ```

2. **Navegue até o diretório:**

   ```bash
   cd personal-portfolio
   ```

3. **Abra o arquivo `index.html` em seu navegador** ou use um servidor local:

   ```bash
   # Usando Python
   python -m http.server 8000

   # Usando Node.js (http-server)
   npx http-server
   ```

4. **Acesse no navegador:**
   ```
   http://localhost:8000
   ```

## 📫 Contribuir

Contribuições são muito bem-vindas! Se você deseja contribuir com o projeto, por favor, siga estes passos:

1.  **Faça um Fork** do repositório.

2.  **Crie uma nova Branch** para sua feature ou correção:

    ```bash
    git checkout -b feature/nome-da-feature
    ```

3.  **Faça suas alterações** e realize o commit:

    ```bash
    git commit -m "feat: Adiciona nova feature"
    ```

4.  **Envie suas alterações** para o seu fork:

    ```bash
    git push origin feature/nome-da-feature
    ```

5.  **Abra um pull request** para a branch `main` do repositório original.
